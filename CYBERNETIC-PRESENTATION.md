# The Cybernetic Teammate

A 16:9 English reading-oriented Beamer presentation using the original CCM4 theme.

## Build

Select `cybernetic-teammate.tex` as the main document in Overleaf and use pdfLaTeX.

```sh
latexmk -pdf cybernetic-teammate.tex
```
