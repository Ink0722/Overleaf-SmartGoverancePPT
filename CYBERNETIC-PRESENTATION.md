# The Cybernetic Teammate — English Beamer Presentation

A 25-frame classroom presentation of Dell'Acqua et al. (2026), *Organization Science*, built with the repository's original CCM4 Beamer theme.

## Build in Overleaf

1. Import or sync this GitHub repository in Overleaf.
2. Set **Main document** to `cybernetic-teammate.tex`.
3. Compile with **pdfLaTeX** (uses the original English font/theme setup).

The source is separated into five editable sections in `cybernetic/`. The original `ccm-example.tex` and existing theme/image files are left untouched.

## Layout and integrity

- 16:9, original CCM4 red/gray branding.
- English-only slide titles, narration, charts, and reference.
- Native LaTeX diagrams and PGFPlots charts for the group matrix, mean quality effects, innovation process, and top-decile outcomes.
- Additional findings are summarized in text; density plots were **not** reconstructed from unavailable underlying raw data.
- The charts reproduce the article's Table 2 Model 1 and Table 9 Model 1 point estimates. See source notes on individual slides.
- **Do not interpret a non-significant difference as proof of equivalence.**
- **550 solutions** are the main performance regression units; **791** denotes randomized professionals.
